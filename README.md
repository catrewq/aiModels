# EC灼厂 - 电商AI创作平台

一个展示电商AI创作能力的可交互Demo，支持智能生图、视频复刻、AI助手三大核心功能。

## 🎯 功能特性

### 1️⃣ 智能生图模块
- ✅ 参数化图片生成（模特、场景、构图、光影、配色）
- ✅ Canvas实时渲染
- ✅ 多阶段进度展示
- ✅ 变体快速生成
- ✅ 图片下载功能

### 2️⃣ 视频复刻模块
- ✅ 视频上传与预览
- ✅ 链接解析（支持抖音/TikTok/YouTube）
- ✅ 模拟分析进度
- ✅ 脚本提取展示
- ✅ 关键帧可视化

### 3️⃣ AI助手模块
- ✅ 智能对话系统（基于关键词匹配）
- ✅ 上下文记忆功能
- ✅ 图片上传识别
- ✅ 语音输入模拟
- ✅ 动态表单生成
- ✅ 营销文案生成与复制

## 🚀 快速开始

### 本地预览
直接用浏览器打开 `index.html` 即可。

### 部署到线上

#### 方案1：GitHub Pages（推荐）
1. 在GitHub创建新仓库
2. 上传项目文件（`index.html` 和 `README.md`）
3. 进入仓库设置 → Pages → 选择 `main` 分支 → 保存
4. 等待1-2分钟，访问 `https://你的用户名.github.io/仓库名/`

#### 方案2：Vercel（最快）
1. 访问 [vercel.com](https://vercel.com)
2. 导入GitHub仓库
3. 点击部署，自动生成线上地址

#### 方案3：Netlify
1. 访问 [netlify.com](https://netlify.com)
2. 拖拽项目文件夹到页面
3. 自动部署，生成线上地址

## 💡 使用说明

### 智能生图
1. 在左侧面板选择参数（模特、场景、构图等）
2. 点击"一键生成"按钮
3. 观察多阶段进度展示
4. 查看生成的图片和变体
5. 点击"下载"按钮保存图片

### 视频复刻
1. 上传本地视频（MP4/MOV，最大500MB）或粘贴视频链接
2. 点击"解析"按钮
3. 观察分析进度
4. 查看提取的脚本、关键帧和高光节点
5. 点击"一键生成短视频"完成创作

### AI助手
1. 在对话框描述您的需求（如"我需要为夏季新款连衣裙生成电商素材"）
2. AI会自动分析并生成定制化表单
3. 填写表单（商品名称、目标受众、营销风格）
4. 点击"智能生成套图"
5. 查看生成的营销文案和套图
6. 点击"复制文案"按钮复制营销文案

## 🎨 技术栈
- 纯HTML + CSS + JavaScript（单文件架构）
- Canvas API（图片生成）
- FileReader API（文件上传预览）
- CSS Animations（动画效果）
